Official integration setup in one place. This page provides the safe setup paths and readiness checklist; a provider is not shown as connected until OAuth credentials and a trusted backend are configured and tested.

GH
Code & repositories

GitHub

Setup required

Planned workflow: inspect selected repositories, create a working branch, propose code changes, run checks, and open a pull request for your review.

  • Use a GitHub App with repository-scoped permissions.
  • Start read-only; request write access only when needed.
  • Keep private app credentials on the backend, never in browser code.

G
Email & identity

Google / Gmail

Setup required

Google sign-in and Gmail are separate permissions. The existing project has setup notes for Google sign-in; Gmail access needs its own OAuth scopes and consent.

  • Begin with Gmail read-only or draft creation.
  • Ask before sending, deleting, or modifying messages.
  • Use the minimum scopes required and provide a disconnect path.

M
Social publishing

Facebook & Instagram

Eligibility check

Use Meta's official APIs for supported Page and professional-account workflows. Available permissions depend on account type, app review, and Meta policy.

  • Do not assume access to personal inboxes or every group.
  • Request only the Page/Instagram permissions the feature needs.
  • Require user review before publishing content or sending messages.

WA
Business messaging

WhatsApp Business

Setup required

Use the official WhatsApp Business Platform / Cloud API for eligible business messaging. This is not a way to automate a personal WhatsApp account.

  • Configure a Meta business app and eligible business number.
  • Store access tokens and webhook verification on the backend.
  • Respect opt-in, approved templates, and messaging limits.

Security boundary — importantGitHub Pages is static hosting, so it cannot safely hold client secrets or long-lived provider tokens. The current Gemini browser-key setting is local to the browser and is not a secure vault. Before enabling live GitHub/Gmail/Meta actions, deploy a backend, add encrypted token storage, least-privilege scopes, revocation, audit logs, rate limits, and explicit confirmation for consequential actions. Never commit API keys or OAuth client secrets to this repository.
