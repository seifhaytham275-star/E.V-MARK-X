About the project

A focused, modern AI workspace.

E.V-MARK-X is an independent AI workspace for learning, planning, and brainstorming. The chat is configured to use Gemini 3.5 Flash-Lite only.

Open AI Workspace ↗

How it works

The public interface is hosted on GitHub Pages. Open the workspace and enter your own Gemini API key in Settings. Chat requests go directly from this browser to Google's Gemini API and use Gemini 3.5 Flash-Lite; no Google sign-in or project backend is required for this mode.

Security notes

The API key is stored in this browser's local storage and sent to Google from this device. Browser storage is not a secure vault; only use a trusted personal device and remove the key before sharing the device. Never paste your key into public GitHub files. API access and quotas are controlled by Google and the key's project settings.

This mode does not use Google sign-in or a project account system. Clearing browser storage removes the saved API key.

Privacy and responsible use

  • Do not enter passwords, payment details, private keys, or other sensitive information into prompts.
  • AI-generated answers can be wrong. Verify important information independently.
  • Gemini API usage may have quotas or costs according to the project owner's Google account and service settings.
  • This is an independent project and is not an official Google product.
  • The project owner should review hosting, privacy, and applicable legal requirements before opening the service to the public.
