ذكاء اصطناعي في مساحة عربية بسيطة

E.V-MARK-X مشروع مستقل قيد التطوير يهدف إلى تقديم واجهة سهلة لتجربة موديلات Gemini واستخدامها في التعلّم والتخطيط وصناعة الأفكار من المتصفح.

كيف يعمل؟

الواجهة الثابتة منشورة عبر GitHub Pages. عند إدخال مفتاح Gemini API، يطلب المتصفح قائمة الموديلات المتاحة ثم يرسل رسائلك إلى خدمة Google Gemini. الموديلات التي تظهر تعتمد على ما تتيحه Google لمفتاحك في وقت الاستخدام.

مهم: حدود الأمان

هذه النسخة لا تحتوي على خادم خلفي. لذلك لا تضع مفتاحًا مشتركًا أو مفتاحًا مخصصًا لخدمة عامة داخل الصفحة، ولا تشارك مفتاحك مع الآخرين. المفتاح لا يُحفظ في التخزين المحلي أو قاعدة بيانات الموقع، ويُستخدم من ذاكرة الصفحة، لكنه يظل قابلًا للرؤية لصاحب الجهاز وأدوات المطور. استخدام ترويسة API بدل عنوان الرابط يقلل ظهوره في السجلات التي تحفظ عناوين الطلبات، لكنه لا يجعل مفتاح المتصفح سرًا.

إذا أردنا أن يستخدم الجميع حساب API واحدًا، يجب أولًا إضافة خادم وسيط آمن مع حفظ المفتاح في متغيرات بيئة سرية، وحدود للطلبات لكل مستخدم، ومراقبة للتكلفة، وحماية من إساءة الاستخدام. لا توفر GitHub Pages وحدها هذه الوظائف الخلفية.

الخصوصية والاستخدام المسؤول

  • لا تدخل كلمات مرور أو بيانات شخصية حساسة أو أسرار عمل.
  • راجع إجابات الذكاء الاصطناعي قبل الاعتماد عليها؛ قد تحتوي على أخطاء.
  • قد تترتب تكلفة أو حدود استخدام على Gemini API حسب حسابك وإعداداته وسياسات Google.
  • هذا مشروع مستقل وليس منتجًا رسميًا من Google.
