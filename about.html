About the project

A focused, modern AI workspace.

E.V-MARK-X is an independent project in development that aims to make it easier to explore AI models for learning, planning, and brainstorming through a clean web interface.

Continue with Google ↗

How it works

The public interface is hosted on GitHub Pages. Google Identity Services provides a sign-in credential, which the backend verifies with Google's authentication library. The backend then lists available Gemini models and forwards chat requests to Google using a server-side API key. The key must never be included in public HTML, JavaScript, or client configuration.

Security notes

The login and chat flow will work only after the backend is deployed and configured with a Google OAuth Web Client ID and a Gemini API key. The Gemini key must be stored as a secret environment variable on the backend host. The backend includes request rate limits and checks model names against the models available to that key, but rate limits are not a substitute for usage quotas and billing alerts.

Google sign-in confirms account identity; it does not automatically create a user database or provide permanent user accounts. This version keeps the Google credential in the current browser tab's session storage. Avoid shared devices and sign out when finished.

Privacy and responsible use

  • Do not enter passwords, payment details, private keys, or other sensitive information into prompts.
  • AI-generated answers can be wrong. Verify important information independently.
  • Gemini API usage may have quotas or costs according to the project owner's Google account and service settings.
  • This is an independent project and is not an official Google product.
  • The project owner should review hosting, privacy, and applicable legal requirements before opening the service to the public.
